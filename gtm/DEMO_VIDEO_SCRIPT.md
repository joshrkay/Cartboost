## On-Camera Talent Notes

**If showing on-camera talent (founder/employee):**
- Casual but professional (polo shirt, good lighting)
- Genuine smile when talking about results
- Point at screen when showing features
- Maintain eye contact when delivering problem/solution
- Energy level: Conversational, not salesy

**If voice-over only:**
- Warm, friendly tone
- Medium pace (slower than typical speech)
- Natural inflection, not robotic
- Emphasize benefits (free, easy, results)

---

## Audio Notes

- **Background music:** Upbeat, modern, non-distracting (Epidemic Sound, Artlist recommendations: "Growth", "Momentum", "Rise")
- **SFX:** Subtle UI sounds for clicks/animations (not overdone)
- **Voice:** Professional male or female voice, Upwork/Fiverr recommended for $100-200
- **Voiceover timing:** Leave 0.2-0.3 seconds between sentences for B-roll transitions

## Production Checklist

**Pre-Production:**
- [ ] Record voiceover (if VO-only option)
- [ ] Select background music track
- [ ] Gather app screenshots/screen recordings
- [ ] Design graphics (charts, icons, animations)
- [ ] Set up lighting for on-camera talent (if applicable)

**Production:**
- [ ] Screen recording of app (1080p minimum)
- [ ] On-camera footage (if used)
- [ ] Multiple takes of critical sections
- [ ] Test audio levels

**Post-Production:**
- [ ] Edit B-roll to script timing
- [ ] Add animations/transitions (smooth, professional)
- [ ] Color grade for consistency
- [ ] Add captions/subtitles (YouTube, social)
- [ ] Mix audio (VO + music + SFX)
- [ ] Export in multiple formats:
  - 1080p MP4 (YouTube, website)
  - 16:9 (1920x1080) for desktop
  - 9:16 vertical (1080x1920) for Instagram Reels/TikTok
  - 4:5 (1080x1350) for Instagram feed

**Review:**
- [ ] Watch full length, full sound
- [ ] Check pacing (feels natural?)
- [ ] Verify all key messages included
- [ ] QA: No spelling errors on screen text
- [ ] Ensure Shopify app store listing visible

## Alternatives if Recording Full Demo

**Option A: Animated Explainer (Higher Production Value)**
- Similar script
- Animated characters/graphics
- Cost: $500-2,000 (outsourced)
- Benefit: Very polished, shareable, reusable

**Option B: Live Screen Recording + VO (Fastest & Cheapest)**
- Record actual app demo
- Voiceover on top
- B-roll from marketing/stock footage
- Cost: $100-300
- Benefit: Authentic, fast turnaround, shows real product

**Option C: Founder Talking Head + Screen (Most Personal)**
- Founder speaks directly to camera
- Interspersed with app demos
- B-roll in background
- Cost: $200-500
- Benefit: Builds founder connection, authentic

**Recommendation:** Option B (Live Screen Recording + VO) - fastest, cheapest, most authentic for a soft launch. Can upgrade to Option A later if resources allow.
